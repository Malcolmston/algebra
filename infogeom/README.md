# infogeom — implements tools from information geometry

[![Go Reference](https://pkg.go.dev/badge/github.com/malcolmston/algebra/infogeom.svg)](https://pkg.go.dev/github.com/malcolmston/algebra/infogeom)

Package infogeom implements tools from information geometry, the study of
probability distributions as points on differentiable (statistical) manifolds
equipped with the Fisher-Rao metric and the family of alpha-connections.

- divergences between discrete probability distributions represented as plain
[]float64 slices whose entries are non-negative and sum to one: the
Kullback-Leibler, Jensen-Shannon, Renyi, Tsallis, chi-squared, Hellinger,
total-variation, Bhattacharyya and general f-divergences, together with the
Amari alpha-divergence family;

## Install

```sh
go get github.com/malcolmston/algebra@v0.8.0
```

```go
import "github.com/malcolmston/algebra/infogeom"
```
